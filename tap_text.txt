1.1 – Justificativa do Projeto (necessidade do negócio)

O futebol é um esporte que atrai grande interesse do público durante competições internacionais, especialmente durante a Copa do Mundo. Nesse período, torcedores buscam informações sobre partidas, estatísticas e análises de desempenho das seleções.Com o crescimento da tecnologia e da análise de dados no esporte, plataformas digitais passaram a ser a forma principal de acompanhar as competições. Muitos usuários desejam não apenas visualizar o placar de uma partida, mas também os aspectos estatísticos do jogo, como número de chutes, posse de bola, faltas e outros indicadores de desempenho. Entretanto, grande parte dessas informações encontra-se dispersa em diferentes plataformas ou não apresenta estimativas claras de probabilidade de vitória entre as equipes. Dessa forma, surge a necessidade de desenvolver uma plataforma digital que engloba todas essas informações e permita aos usuários acompanhar as partidas de forma mais analítica e organizada.

Diante desse contexto, o presente projeto propõe o desenvolvimento de uma plataforma web voltada para a visualização de estatísticas de partidas da Copa do Mundo e para a apresentação de estimativas de probabilidade de vitória entre as seleções contribuindo para uma melhor experiência de acompanhamento das partidas.

1.2 – Descrição do produto do projeto

O projeto consiste no desenvolvimento de uma plataforma web destinada à estatísticas e previsões relacionadas a partidas da Copa do Mundo. A plataforma será acessível por meio de navegadores em computadores e dispositivos móveis, permitindo que os usuários acompanhem informações relevantes sobre partidas entre seleções participantes antes, durante e após a competição. O sistema contará com diferentes páginas e funcionalidades principais, incluindo:

Uma página inicial a qual apresentará uma lista de partidas disponíveis, exibindo informações básicas como seleções participantes, horário do jogo e status da partida (em andamento, finalizada ou futura).

Uma página de detalhes de partidas onde exibirá informações completas sobre a partida selecionada, incluindo: Placar atual da partida, estatísticas do jogo e lista de eventos importantes da partida (gols, cartões e outras ocorrências).

Cada seleção participante possuirá uma página própria contendo informações como: Histórico de partidas, desempenho recente, média de gols marcados e sofridos, além de estatísticas gerais da equipe.

A plataforma também apresentará estimativas de probabilidade de vitória entre as seleções participantes de uma partida, calculadas a partir de dados estatísticos previamente definidos no sistema.

Por fim, para simular o acompanhamento de partidas em tempo real, o sistema utilizará um mecanismo de consulta periódica ao servidor, no qual a página realizará requisições automáticas em intervalos de tempo definidos para verificar se houve atualização nas informações da partida, como novos gols ou eventos. Esse mecanismo permitirá que os usuários visualizem alterações no placar e nos eventos da partida sem a necessidade de atualizar manualmente a página.

1.4 – Premissas (hipóteses) e restrições para o projeto

Para a realização do projeto, consideram-se as seguintes premissas:

Acesso a computadores, internet e ferramentas de desenvolvimento necessárias para a criação do sistema;

Utilização de tecnologias de desenvolvimento web para implementação da plataforma;

Possibilidade de utilizar dados simulados ou dados públicos para representar as estatísticas das partidas.

O projeto deverá respeitar algumas limitações, são elas:

O desenvolvimento deverá ser concluído dentro do prazo estipulado de 90 dias;

A plataforma não dependerá obrigatoriamente de integração com APIs esportivas externas;

As atualizações das partidas serão simuladas por meio de consultas periódicas ao servidor, sem utilização de infraestrutura complexa de transmissão de dados em tempo real.

1.7 – Objetivos

O objetivo geral do projeto é desenvolver uma plataforma web que permita aos usuários acompanhar estatísticas de partidas da Copa do Mundo e visualizar estimativas de probabilidade de vitória entre as seleções participantes.

Objetivos Específicos

Desenvolver interface web para visualização de partidas e seleções;

Implementar sistema de listagem de jogos disponíveis;

Criar página de detalhes das partidas com estatísticas e eventos;

Desenvolver mecanismo de atualização automática das informações;

Implementar sistema de cálculo de probabilidade de vitória entre equipes;

Organizar banco de dados para armazenamento das informações das seleções e partidas.
